# Live against new

The live fingerprint page beside the new app's `/fingerprint`, drawn at the same size, made
2026-09-21 by the builder seat. The live side is exactly the page's own assets: all 15 live images are
byte-identical to `_theme/assets` (SHA-256), and the live carousel is the page's own `fingerprint.js`
run on the three seed rows.
