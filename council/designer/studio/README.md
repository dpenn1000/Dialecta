# Studio

Where ideas live before they have evidence.

Everything else this advisor owns is convergent by design. `research/` holds one file per source.
`positions.md` carries confidence and a citation on every row, and a row with no filed note behind
it is marked `(unsourced)`. That bar is right, and it is why the palette audit is worth anything.

It is also why nothing new ever got written down. A new idea has no citation. If it had one it
would be somebody else's idea. So the quality gate that makes the positions trustworthy was
filtering the generative work out before it reached a file.

This folder is exempt from the sourcing rule, and from nothing else.

## The contract

One file per idea, `NNN-<slug>.md`, four headings and nothing else:

```markdown
## The idea
Two or three sentences. What it is, not why it is good.

## What it is for
The named Dialecta surface and the contributor behaviour it is meant to change.

## What would kill it
The observation, measurement or spec section that ends this idea. Written before anyone
looks, so the idea cannot quietly move its own goalposts.

## What it costs to find out
The smallest thing that would settle it. A harness page, ten minutes with one contributor,
one query. If the answer is "build the feature", the idea is not ready.
```

## How an idea leaves

Three ways out, and it must take one. An idea that sits here for two sprints without moving is
closed as `abandoned` with the reason, the same as an exchange record.

- **Promoted.** Evidence arrived. It becomes a row in `positions.md` with a real citation, and the
  studio file is closed with a pointer to it.
- **Killed.** The thing under `What would kill it` happened. Closed with what killed it. This is
  worth as much as a promotion and costs less.
- **Handed over.** It is somebody else's call. Goes to `exchange/` as a record and closes here.

## What this folder is not

Not a backlog. Not a place to park work. Not a licence to argue from a hunch in council, where
`(unsourced)` still applies and always will. A studio file has no standing in a debate until it has
left this folder through one of the three doors above.

It is also not exempt from Editorial Voice v1.2. The hard rules cost nothing to keep and a sketch
that cannot survive them was going to need rewriting anyway.
