## What the sprints found

**The deployed API is not in any repository.** Production serves from Vercel deployment
`dpl_HPsXrGxyeCSCRBSHF9fBHExGjrR7`, created 2026-05-08 from a workstation, recording commit
`53364fa` against `dpenn1000/dialecta-api`. GitHub answers 422 for that SHA. The repository's last
push was 2026-04-28 and its `main` holds 11 files under `api/` against the deployment's 38, and none
of the difference is anywhere on this machine. The artifact is the only copy of the code serving
the platform, and it has served unchanged for four and a half months. This is why the seat exists:
no diff review reaches this code, and no `git log` can describe it.

**The grants question is settled by measurement, and the answer holds the reviewer's blocker up.**
All 30 tables in `public` grant SELECT, INSERT, UPDATE and DELETE to both `anon` and
`authenticated`. Record 2026-09-19-002 made B2's severity conditional on their absence. They are
present, so B2 does not drop. Live writes are nonetheless closed, because no table carries a write
policy any public role can satisfy, which is a fact about the live schema and not about the
migration under review. The two must not be averaged: the proposed foundation migration adds owner
writes own row policies, and those land on grants that are already open.

The first reading of this was exactly inverted. `information_schema.role_table_grants` returned no
grants for either role, which reads as a closed database. The view shows only grants for a role the
session holds. `has_table_privilege` asks directly and is not filtered.

**`SECURITY DEFINER` and storage both came back clean**, which is worth as much as a finding. One
definer function, hardened and unreachable by either public role. One view, invoker scoped. One
bucket, `feedback-screenshots`, public read and empty. `article-media` does not exist on the live
project at all; the lead assumed it from a migration nobody has applied.

**The comment endpoint's credential may be published by the database.** The deployed
`api/comment.js` docblock states its auth model as receiving `member_uuid` and resolving
`profiles.ghost_member_id`. `profiles_select` is `USING (true)` for `public` with no column grants,
and 8 of 14 rows carry a `ghost_member_id` in the UUID shape Ghost's `{{@member.uuid}}` emits. The
handler body is unread, so this is ranked high rather than critical and the note says so on its
face.

**Seven deployed routes call Anthropic and it is unknown for all seven whether they need
credentials.** Vercel Hobby has no Spend Management at any price, so a ceiling has to come from the
Anthropic side. The structural fix on the injection half is an `enum` output schema rather than
better prompt wording, which is also what OWASP and the current design patterns literature say.

**The liability half is more concrete than expected.** Connecticut's privacy act threshold dropped
to 35,000 consumers and gained two triggers with no consumer floor at all, one of which is any
processing of sensitive data. Whether a Thinking Fingerprint is sensitive data therefore decides
whether the act reaches Dialecta at 14 members. Separately, Travelers rescinded a cyber policy
outright rather than denying a claim, because the application overstated where MFA applied.
